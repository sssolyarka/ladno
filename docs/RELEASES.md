# Установщики Ладно

Готовые файлы публикуются в [GitHub Releases](https://github.com/sssolyarka/ladno/releases). Репозиторий приватный: для скачивания нужен вход в разрешённый аккаунт GitHub.

## Fedora x86_64

Скачайте `ladno-ВЕРСИЯ-fedora-x86_64.rpm`, откройте системным установщиком или выполните `sudo dnf install ./ladno-ВЕРСИЯ-fedora-x86_64.rpm`. После установки «Ладно» появится в меню приложений. Программа установлена в `/opt/ladno`; данные остаются в пользовательской папке. Удаление пакета не удаляет заметки.

Дополнительно доступен архив `linux-x64.tar.gz`: распакуйте, откройте каталог `bundle`, запустите `ladno`, сохранив соседние папки. Linux-сборка на Ubuntu 22.04 использует более старую glibc и предназначена для современных Fedora; совместимость проверяется отдельно от компиляции.

## Windows 10/11 x64

Скачайте `ladno-ВЕРСИЯ-windows-x64-setup.exe` и запустите. Установка для текущего пользователя, с русским мастером, ярлыком в меню и обычным удалением через «Приложения». Администратор не требуется. Данные приложения не удаляются деинсталлятором.

Установщик и EXE пока без платной подписи Authenticode: Windows может показать неизвестного издателя. Контрольные суммы опубликованы в SHA256SUMS.txt. Проверять установку надо на отдельной Windows 10, а не только на сборочной Windows-системе.

## Android

Скачайте `ladno-ВЕРСИЯ-android.apk` на телефон и откройте. Разрешите установку из выбранного браузера/файлового менеджера, если Android запросит. APK универсальный для поддерживаемых Flutter архитектур; Google Play не нужен. Минимальный Android зависит от закреплённого Flutter (API 24+).

APK собирается в режиме release и подписывается постоянным приватным ключом из GitHub Actions Secrets. При обновлении сохраняйте тот же ключ, applicationId и увеличивайте номер после `+` в pubspec.yaml. Новый ключ не сможет обновить прежнюю установку. Удаление приложения удаляет локальные заметки: сначала сделайте резервную копию. Ключ не хранится в репозитории или Releases.

## Повторный выпуск

Actions → «Установщики и релиз» → Run workflow. Версия берётся из pubspec.yaml, тег — `vВЕРСИЯ`. Публикация выполняется только после успешных тестов и всех сборок. Релизы этапа 1 помечаются prerelease. Повторный запуск для существующего релиза прекращается без перезаписи установщиков: для изменений увеличьте версию.

Секреты Android: `ANDROID_KEYSTORE_BASE64` (JKS, alias ladno), `ANDROID_KEYSTORE_PASSWORD` (одинаковый пароль keystore и key, URL-safe ASCII). Они доступны только Android job, не Linux/Windows. GITHUB_TOKEN с contents:write используется только для публикации релиза. Сборка запускается вручную, не из внешних pull requests. Копию ключа и пароль храните отдельно от GitHub.

Эти установщики содержат первый этап: заметки, папки, поиск, корзину и копии. Синхронизация, задачи, уведомления, привычки и фокус пока отсутствуют. Успешная сборка не заменяет проверку установки на реальных устройствах.
