## Что требует ручной проверки

- Android: установка, экранная клавиатура, системные файловые диалоги, Scoped Storage, сохранение/восстановление после перезапуска на реальном телефоне.
- Windows 10: мастер установки, файловые диалоги и сохранение на реальном ПК. Проверка Server 2022 не заменяет Windows 10.
- Fedora: установка/обновление RPM через dnf, нативные диалоги экспорта/импорта, доступность со скринридером. При кратком локальном запуске GTK сообщал предупреждения о курсоре/ATK; база создавалась и запуск проходил.
- Аварийное отключение питания, заполнение диска и kill во время записи: fault-injection проверки ОС пока нет.
- Синхронизация, TLS/QR/mDNS, конкурентное редактирование двух устройств, вложения/обрывы, разница часов, старый peer, повторяющиеся задачи и уведомления ещё не реализованы. Успешная сборка ничего не подтверждает об этих функциях. План проверок — ROADMAP.md.
