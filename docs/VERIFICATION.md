## Автоматические проверки

Flutter **3.47.9 stable**, Dart **3.13.7**. Зависимости зафиксированы в `pubspec.lock`, CI требует `--enforce-lockfile`. GitHub Actions закреплены полными SHA.

`dart analyze lib test` — без замечаний. `flutter test --no-pub` — **16 успешных проверок**, включая 11 хранилища и 5 интерфейса, повторены на GitHub перед сборками.

Хранилище: пустая база без демоданных, сохранение Unicode после закрытия/открытия, русский поиск, корзина/восстановление, история 30 редакций, рост версии со старым снимком, удаление папки без потери заметок, полная копия и восстановление, исключение настроек/секретов, повреждённая копия без изменения базы, несовместимая версия, безопасные UUID-имена Markdown, семь автокопий, отказ слишком длинному тексту без изменения сохранённой записи.

Интерфейс: 1440×900, 390×844 и 320×640 в светлой теме; 1440×900 и 390×844 в тёмной. Создание, заголовок/тело, сохранение в базе, статус, предпросмотр Markdown и возврат к списку. PNG просмотрены визуально. Никаких тестовых записей в пользовательской базе.

## Что требует ручной проверки

- Android: установка, экранная клавиатура, системные файловые диалоги, Scoped Storage, сохранение/восстановление после перезапуска на реальном телефоне.
- Windows 10: мастер установки, файловые диалоги и сохранение на реальном ПК. Проверка Server 2022 не заменяет Windows 10.
- Fedora: установка/обновление RPM через dnf, нативные диалоги экспорта/импорта, доступность со скринридером. При кратком локальном запуске GTK сообщал предупреждения о курсоре/ATK; база создавалась и запуск проходил.
- Аварийное отключение питания, заполнение диска и kill во время записи: fault-injection проверки ОС пока нет.
- Синхронизация, TLS/QR/mDNS, конкурентное редактирование двух устройств, вложения/обрывы, разница часов, старый peer, повторяющиеся задачи и уведомления ещё не реализованы. Успешная сборка ничего не подтверждает об этих функциях. План проверок — ROADMAP.md.
