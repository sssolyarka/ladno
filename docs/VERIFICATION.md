# Выполненные проверки — 09.11.2026

Среда: Fedora Linux x64; Flutter **3.47.9 stable**, Dart **3.13.7**. Версии библиотек зафиксированы в `pubspec.lock`.

## Результаты

- `dart analyze lib test`: без замечаний после исправлений.
- `flutter test --no-pub --reporter expanded`: 16 проверок (11 хранилища, 5 интерфейса). Итоговый журнал включён в `artifacts/tests.log`.
- `flutter build linux --release --no-pub`: Fedora release-сборка. Переносимая папка содержит исполняемый файл и библиотеки; распространять её целиком.
- Реальный краткий запуск Fedora release в текущей графической сессии: процесс продолжал работать, создал новую SQLite без демонстрационных записей (0 заметок), `PRAGMA integrity_check` вернул `ok`. Процесс проверки закрыт, использовалась отдельная временная папка данных.
- GTK сообщил предупреждения о теме курсора и доступности `atk_socket_embed`; запуск и создание базы прошли. Доступность со скринридером отдельно не проверена.

## Хранилище

Пустая база, сохранение Unicode после закрытия/открытия, русский поиск без учёта регистра, удаление в корзину и восстановление, ограничение истории 30 версиями, рост версии со старым снимком, удаление папки без потери заметок, полная копия и восстановление (папки/корзина/история), исключение настроек и условного секрета из экспорта, повреждённая копия без изменения текущей базы, несовместимая версия, безопасные UUID-имена экспорта, лимит семи автоматических копий, отказ слишком длинному тексту без изменения сохранённой версии.

## Интерфейс

Widget-тесты на 1440×900, 390×844 и 320×640 в светлой теме; 1440×900 и 390×844 в тёмной. Проверены создание, ввод заголовка/тела, запись в базу, статус сохранения, предпросмотр Markdown и возврат к списку. Исключения разметки приводят к падению теста. PNG в `artifacts` просмотрены визуально: настольный редактор и предпросмотр, светлая/тёмная темы, мобильный список с нижней навигацией и редактор. Шрифты теста берутся из Flutter SDK и системного Liberation Sans, если он доступен. Эти изображения — тестовые данные, не начальная пользовательская база.

## Не проверено

- Android: нативная сборка, реальный телефон, экранная клавиатура, установка, фон, системный выбор файлов и Scoped Storage. Android SDK в этой среде отсутствует; APK не выпущен.
- Windows 10: сборка и запуск на реальной Windows, SQLite DLL, системные файловые диалоги. Проект и инструкция есть; EXE для Windows не выпущен.
- Нативные диалоги экспорта/импорта Fedora вручную не проходились. Проверены сами функции файлового экспорта и транзакционного восстановления.
- Аварийное отключение питания, заполнение диска, kill во время записи: SQLite настройки и обработка ошибок предусмотрены, fault-injection теста ОС ещё нет.
- Синхронизация, сеть, TLS/QR/mDNS, конфликты двух устройств, вложения и их обрыв, часы устройств, возвращение старого peer, повторяющиеся задачи и уведомления: ещё не реализованы, проверок работающего протокола нет. Требуемые тесты перечислены в ROADMAP.md.

## Особенность инструментов

`flutter analyze` в этой версии инструментов завершился внутренней ошибкой LSP при обработке пути проекта с кириллицей. Прямой `dart analyze lib test` на тех же исходниках завершился успешно. Поэтому README использует эту команду. Успешная компиляция и widget-тесты не считаются проверкой Android/Windows или будущей синхронизации.
