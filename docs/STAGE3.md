# Третий этап — работа начата 12.11.2026

Текущая версия 0.3.0-dev.2 переведена на личный Docker/Pterodactyl-бэкенд за HTTPS-доменом makar.frogville.fun. Прямой LAN/QR-обмен ниже относится к предыдущему состоянию разработки; актуальные подключение и ограничения — README.md и deploy/pterodactyl/README.md. Модель задач, повторов и напоминаний сохраняется.

## Реализовано в рабочей ветке

- Задачи: описание, четыре статуса, четыре уровня приоритета, теги, срок, родительская задача, проект, архив и восстановление.
- Проекты: создание, переименование, завершение, просмотр задач, объединение разных названий.
- Входящие без проекта/срока, Сегодня с просроченными, Предстоящие, общий список, календарь с выбором дня, поиск по тексту и тегам, показ завершённых.
- Задачи и проекты находятся в общем причинном журнале второго этапа, передаются тем же TLS-транспортом, входят в полный архив. Конфликтующие варианты доступны в редакторе задачи. Операция завершения не перезаписывает другие поля.
- Повторы ежедневно/еженедельно/ежемесячно. Следующая задача появляется после завершения. UUID v5 от текущей задачи + `next` одинаков на всех устройствах. Завершение и создание преемника — одна транзакция. Повторное завершение не создаёт дублей; месячный повтор сохраняет исходный день (31 января → 28/29 февраля → 31 марта).
- Напоминания включаются отдельно на каждом устройстве. Android/Windows передают ближайшие 64 будущих напоминания ОС, Linux использует таймеры только при работающем приложении. Завершение, архив, изменение даты и восстановление копии пересчитывают очередь. Прошедшие уведомления не переигрываются после запуска.
- Android: запрос разрешения уведомлений только при включении, inexactAllowWhileIdle без специального разрешения точных будильников, receivers для перезагрузки и обновления. Иконка сохранена от удаления оптимизатором.

## Правила и границы

Срок — календарная дата без часового пояса. Напоминание — абсолютный момент времени. При повторе сохраняется смещение UTC относительно календарного срока; после перехода на летнее/зимнее время местный час может сдвинуться. При необходимости измените время напоминания. Следующая задача не создаётся заранее и не переносит завершение на всех детей автоматически. Возврат завершённой задачи в работу не удаляет уже созданного преемника.

Родительские циклы запрещены при локальном редактировании. Сетевые конкурентные связи отображаются плоским списком, поэтому не вызывают рекурсивного зависания. Удаление родителя не удаляет подзадачи. Проект можно завершить отдельно от его задач.

Для обмена задачами обновите все устройства до версии третьего этапа. 0.2.1 не знает новые типы операций и отклоняет их. Не открывайте базу/копию третьего этапа старой версией.

Разрешения, состояние планировщика и очередь уведомлений локальны, не экспортируются и не синхронизируются. Выполнение задачи на другом устройстве отменяет уведомление только после обмена. Android может задерживать неточные уведомления; принудительная остановка и ограничения производителя влияют на доставку. ОС решает, что видно на заблокированном экране. Ошибка уведомлений не отменяет сохранённую задачу.
