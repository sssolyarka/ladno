# Резервные копии и восстановление

Настройки → «Полная резервная копия» создаёт `.ladno` с заметками, корзиной, папками, историей, журналом конфликтов и файлами вложений, включая прежние операции. Копия не зашифрована. Храните её отдельно от компьютера и не публикуйте личные данные.

## Формат

ZIP без сжатия, максимум 256 МБ. В нём `snapshot.json` (до 50 МБ) и `files/SHA256`. JSON содержит оболочку `format: ladno-backup`, `version: 2`, `sha256`, `payload`; в payload таблицы folders/notes/revisions и operations. Хеш payload считается по исходным байтам UTF-8. Для каждого вложения проверяются размер и SHA-256. Пути вне разрешённого формата, ссылки, повторные имена и сжатые ZIP-записи отклоняются. Это контейнер данных приложения, не средство распаковки произвольных ZIP.

Секреты, ключи, доверенные устройства, настройки и подтверждения доставки не включены. UUID происхождения в журнале — открытые идентификаторы операций, не ключи. Копии JSON v1/v2 без вложений поддерживаются; для файлов используйте полный `.ladno`.

## Автоматические копии

На ПК: проверка локальной даты при запуске, возвращении и раз в час. Хранятся семь auto-*.ladno. Закрытое приложение расписание не выполняет. Android-автокопий нет. Файл записывается во временный .tmp с flush и переименовывается после завершения. Если вложение ещё не скачано или превышен общий лимит, полная копия не выдаётся за успешную.

## Восстановление

Выберите файл через настройки. Сначала проверяются весь архив, сумма снимка, типы, UUID, ссылки таблиц и все вложения; затем показывается число заметок и предупреждение о замене. После подтверждения создаётся before-restore копия текущих данных и останавливается сеть. Файлы помещаются в кеш по проверенным хешам, база заменяется транзакционно; ошибка базы откатывает записи. Возможные неиспользуемые файлы кеша после отказа не становятся заметками.

Восстановленная база получает новый идентификатор устройства, прежние открытые редакторы инвалидируются, доверие сбрасывается. Свяжите устройства заново. Это замена снимком, не двустороннее объединение и не способ повседневного обмена.

## Markdown

Экспорт создаёт отдельный каталог: UUID.md для активных заметок, ссылки на файлы в files/SHA256, логический ladno-export.json и полный ladno-full.ladno. Для восстановления с файлами выбирайте полный .ladno. JSON удобен для обработки данных, но сам не содержит байты вложений. Произвольный импорт .md пока отсутствует.

Синхронизация не является резервной копией. SHA-256 обнаруживает повреждение, но не удостоверяет автора и не шифрует архив.
