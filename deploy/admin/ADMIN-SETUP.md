# Для системного администратора: Ладно на Debian 13

Домен: `makar.frogville.fun`. Используется существующий Nginx на 443 и отдельный allocation контейнера Pterodactyl. Пароль панели не требуется этому скрипту и в комплект не включён.

Передать администратору файл `setup-ladno.sh`. Он самостоятельно загружает опубликованный исходный комплект 0.3.0 и проверяет закреплённый SHA-256. Docker/Wings и Nginx должны быть уже установлены на узле.

## Подготовить образ

```bash
sudo bash setup-ladno.sh prepare
```

Исходники: `/opt/ladno`. Образ: `ladno-backend:pterodactyl`. Скрипт не перезаписывает существующий каталог. Если скачивание/сборка были прерваны после распаковки, повторить только сборку:

```bash
sudo bash setup-ladno.sh build
```

## Действия администратора панели

Импортировать `/opt/ladno/deploy/pterodactyl/egg-ladno.json` в Nests. Создать сервер с этим EGG и доступным на данном узле образом. Выделить свободный allocation (например 18080), от 1 ГБ памяти и 15 ГБ диска. Порт задаёт панель через SERVER_PORT, данные сохраняются в /home/container/data.

Если Wings требует registry вместо локального образа, администратор размещает собранный образ в своём registry и меняет Docker Image сервера. Docker socket и привилегированный режим контейнеру не нужны.

Запустить сервер; в консоли появится `Ladno backend listening`. Прямой HTTP allocation закрыть от внешних подключений средствами действующего firewall/Docker, сохранив доступ с машины Nginx. Скрипт намеренно не меняет firewall других серверов.

## Подключить Nginx

Заменить параметры на реальный allocation, IP его привязки и пути сертификата. Если allocation доступен с хоста через публичный IPv4, передать его в --upstream-host вместо 127.0.0.1.

```bash
sudo bash setup-ladno.sh proxy \
  --port 18080 --upstream-host 127.0.0.1 \
  --cert /etc/letsencrypt/live/makar.frogville.fun/fullchain.pem \
  --key /etc/letsencrypt/live/makar.frogville.fun/privkey.pem
```

DNS домена должен указывать на эту машину. Скрипт проверяет health контейнера и текущий Nginx, отказывается дублировать уже существующий сайт домена, добавляет только отдельный ladno-makar.conf и делает nginx -t перед reload. Порты 80/443 не освобождаются; остальные vhost сохраняются. Если сайт домена уже существует, его объединяет администратор вручную.

Проверить правильный HTTPS-сертификат и совпадение сервера за доменом:

```bash
sudo bash setup-ladno.sh check --port 18080 --upstream-host 127.0.0.1
```

## Подключить приложения

В приватной консоли сервера: `invite`. Код действует 10 минут и используется один раз. В приложении 0.3.0: Настройки → Синхронизация с сервером → https://makar.frogville.fun → имя устройства → код. Для каждого устройства отдельный код.

Остальные команды: `devices`, `revoke UUID`, `stop`. Коды и доступ к консоли не публиковать. Полная инструкция резервного копирования находится в `/opt/ladno/README.md` и `/opt/ladno/deploy/pterodactyl/README.md`.
