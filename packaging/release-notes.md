Исправление 0.2.1: на ПК обмен продолжается при свёрнутом/неактивном окне; на телефоне фоновый обмен по-прежнему не обещается. Возвращение в приложение сразу запускает попытку обмена.

Второй этап «Ладно»: локальные заметки с прямым защищённым обменом, QR-привязкой, вложениями и объединением конфликтов.

## Установить
- Fedora x86_64: `.rpm`; для ключей подключения нужен работающий разблокированный кошелёк Secret Service.
- Windows 10/11 x64: `windows-x64-setup.exe`, установка для текущего пользователя. Authenticode-подписи пока нет.
- Android: `android.apk`, подписан тем же постоянным ключом, что v0.1.0. Можно обновить установленное приложение.
- Linux: переносимый `linux-x64.tar.gz`, сохраняйте все файлы каталога bundle.

## Подключить
Одна локальная сеть → на обоих устройствах Настройки → «Включить подключение» → показать/сканировать QR или скопировать полный адрес подключения → сравнить код на двух экранах → подтвердить на обоих. Для обмена держите приложение открытым на телефоне. При запросе ОС разрешите частную локальную сеть. При недоступности multicast используйте QR/адрес.

Перед обновлением сохраните копию. Схема базы обновляется с проверяемой предварительной копией; старую версию нельзя запускать на обновлённой базе. После восстановления архива устройства связываются заново. Новый архив содержит файлы и конфликты, не содержит секретов и доверия.

SHA256SUMS.txt содержит контрольные суммы. Выпуск предварительный: сборки и автоматические локальные HTTPS-тесты не заменяют проверки камеры/разрешений/кошелька на реальном Android, Windows 10 и LAN. Задачи, напоминания, привычки, фокус и DeepSeek — следующие этапы.
