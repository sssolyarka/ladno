Ладно 0.3.1 — DeepSeek через личный бэкенд (предварительный выпуск).

- В настройках появился DeepSeek: проверка подключения, отправка введённого текста, копирование ответа.
- Используется существующее HTTPS-подключение устройства к makar.frogville.fun. Ключ DeepSeek хранится только на сервере, не в приложении.
- ИИ получает только текст, который вы явно отправляете; запрос расходует баланс DeepSeek. Заметки и вложения автоматически не передаются, записи не изменяются.
- Владелец должен обновить Docker-образ и настроить ключ. Инструкция: docs/DEEPSEEK.md в исходниках. Данные и токены устройств сохраняются; повторно создавать сервер не нужно.
- Сохранены Android, Windows 10/11 x64 и Linux, заметки, задачи, проекты и синхронизация. Перед обновлением сделайте резервную копию.
- Автоматические тесты используют тестовый API и не подтверждают работу платного аккаунта DeepSeek. Реальная проверка требует серверного ключа.

Контрольные суммы — SHA256SUMS.txt. Коды подключения и API-ключи не публиковать.
