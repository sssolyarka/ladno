Первый устанавливаемый выпуск «Ладно»: локальные заметки, папки, поиск, Markdown, автосохранение, корзина, история и резервные копии.

## Скачать
- **Fedora x86_64**: файл `.rpm` — установить через системный установщик или `sudo dnf install ./ИМЯ_ФАЙЛА.rpm`.
- **Windows 10/11 x64**: файл `windows-x64-setup.exe` — русский мастер установки для текущего пользователя. Издатель пока без Authenticode-подписи.
- **Android**: файл `android.apk` — установить на телефон; APK подписан постоянным ключом выпуска.
- **Другой Linux**: `linux-x64.tar.gz` — распаковать и запустить `bundle/ladno`.

`SHA256SUMS.txt` содержит контрольные суммы. Android APK проверяется apksigner. Windows-установщик проходит тихую установку/удаление и проверку старта на сборочной Windows. Это не заменяет испытание на вашем телефоне и Windows 10.

**Предварительный выпуск первого этапа.** Синхронизация устройств, задачи, уведомления, привычки и фокус ещё не реализованы. Каждое устройство хранит независимые данные. Перед удалением приложения сделайте резервную копию заметок.
