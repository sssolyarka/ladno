Ладно 0.3.0 — задачи и личный HTTPS-бэкенд (предварительный выпуск).

- Android, Windows 10/11 x64 и Fedora: заметки, задачи, проекты, подзадачи, приоритеты, теги, календарь, повторы и локальные напоминания.
- Новая синхронизация через личный сервер по HTTPS. Настройки → Синхронизация с сервером → https://makar.frogville.fun → имя устройства → одноразовый код. Код выдаёт владелец в приватной консоли Pterodactyl командой invite.
- Домен ещё должен быть развёрнут администратором: существующий Nginx → allocation контейнера. EGG, образ Debian 13 и инструкция — deploy/pterodactyl/README.md в исходниках. Не запускайте Compose поверх занятого 443 на узле панели.
- Локальные данные сохраняются без интернета. После подключения история выгружается на сервер; сервер видит содержимое записей. Прямой LAN/QR-обмен заменён серверным.
- Перед обновлением сохраните .ladno-копию. После восстановления архива нужен новый код. 0.2.1 не совместима с новой схемой.
- Android подписан прежним постоянным ключом. Windows Setup не имеет Authenticode-подписи. Linux требует Secret Service для токена.
- Автоматические тесты и контейнерная проверка не заменяют реальный телефон/Windows 10, доставку уведомлений при закрытом приложении и импорт EGG в панель. На Linux напоминания требуют работающего приложения; телефон обменивается данными при открытом приложении.

Контрольные суммы — SHA256SUMS.txt. Не вводите коды и токены в чужие серверы, не публикуйте содержимое приватной консоли панели.
